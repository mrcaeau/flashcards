Ajouter un catalogue JSON

Publier ou tester un deck de cartes

Testez votre fichier JSON instantanément dans votre navigateur :

Glissez votre fichier .json ici

OU COLLER LE JSON
1
Créez votre fichier :

Déposez votre fichier dans data/decks/mon-catalogue.json.

2
Enregistrez-le dans data/catalogs.json : 
{
  "id": "mon-catalogue",
  "title": "Titre du Deck",
  "category": "Langues",
  "icon": "📚",
  "file": "data/decks/mon-catalogue.json"
}
3
Poussez sur Git : 
git add . && git commit -m "Nouveau deck" && git push
Modèle à copier : 
{
  "id": "mon-sujet",
  "title": "Mon Nouveau Sujet",
  "description": "Description concise du deck.",
  "category": "Sciences",
  "icon": "🔬",
  "language": "fr-FR",
  "cards": [
    {
      "id": 1,
      "question": "Quelle est la notion à retenir ?",
      "answer": "La réponse détaillée.",
      "hint": "Un indice facultatif",
      "tag": "Chapitre 1"
    }
  ]
}
