Comment publier un nouveau catalogue sur votre GitHub

Testez votre fichier JSON instantanément dans votre navigateur avant de le pusher sur Git :

Glissez votre fichier .json ici

ou

OU COLLER LE JSON DIRECTEMENT
1
Créez votre fichier de cartes :

Dans votre dépôt local, créez un nouveau fichier dans le dossier data/decks/mon-catalogue.json.

2
Référencez-le dans data/catalogs.json :

Ajoutez une entrée avec le titre, l'icône, la catégorie et le chemin du fichier :

{
  "id": "mon-catalogue",
  "title": "Titre de mon Deck",
  "description": "Courte description...",
  "category": "Langues",
  "icon": "📚",
  "file": "data/decks/mon-catalogue.json"
}
3
Poussez sur GitHub :

Faites un simple commit et push :

git add .
git commit -m "Ajout du catalogue mon-catalogue"
git push origin main

GitHub Pages mettra votre site à jour automatiquement en quelques secondes !

Copiez ce modèle pour créer vos decks : 
{
  "id": "mon-sujet",
  "title": "Mon Nouveau Sujet",
  "description": "Description concise de ce que couvre ce deck de flashcards.",
  "category": "Sciences",
  "icon": "🔬",
  "language": "fr-FR",
  "cards": [
    {
      "id": 1,
      "question": "Quelle est la question ou le terme à deviner ?",
      "answer": "La réponse complète et détaillée.",
      "hint": "Un indice facultatif",
      "tag": "Chapitre 1"
    },
    {
      "id": 2,
      "question": "Deuxième question...",
      "answer": "Deuxième réponse...",
      "hint": "Autre indice",
      "tag": "Chapitre 2"
    }
  ]
}
